Repositori ini mendokumentasikan konfigurasi sistem, otomasi administrasi, dan pipeline infrastruktur untuk homelab Ubuntu Server (CasaOS).
- `scripts/`: Kumpulan bash script otomasi operasional dan backup.
- `systemd/`: Unit file systemd untuk daemon management dan lifecycle process.
- `docs/`: Catatan arsitektur jaringan, hardening firewall (UFW), dan security checklist.
